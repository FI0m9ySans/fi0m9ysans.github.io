模组开发文档

学习如何为番茄闹钟创建模组

快速开始

模组是一个 JSON 文件，可以为番茄闹钟添加新功能。最简单的模组：

{
  "userItems": [
    {
      "id": "my_first_item",
      "name": "我的第一个道具",
      "price": 10,
      "icon": "fa-star",
      "effect": "focus",
      "desc": "专注时间+10分钟！",
      "dependencies": []
    }
  ],
  "backpack": {},
  "tasks": [],
  "customTabs": [],
  "version": "1.0"
}

文件格式

.shom

商品 + 背包
推荐格式

.zid

商品 + 任务 + 标签
完整模组

.taem

任务清单
仅任务

.saop

完整存档
备份进度

效果类型

  • rest — 增加休息时间（如：休息5分钟）
  • focus — 增加专注时间（如：专注+10分钟）
  • tomato — 奖励番茄币（如：获得2个番茄币）
  • exp — 奖励经验值（如：获得25经验）
  • lootbox — 开箱随机奖励
