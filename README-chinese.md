## ✨ 功能特点

- ⏱️ **番茄计时器**：专注工作 25 分钟，完成后获得番茄币和经验值
- 🛒 **商店系统**：购买各种辅助道具（休息、专注加成、开箱等）
- 🎒 **背包系统**：管理和使用已购买的道具
- 📋 **任务系统**：创建任务，完成目标获得奖励
- 🧩 **模组系统**：支持导入/导出 `.shom`/`.shem`/`.zid`/`.zod`/`.taem` 文件
- 🌐 **模组市场**：浏览和安装全球用户分享的模组
- 🌍 **双语支持**：中文 / English 一键切换
- 💾 **存档系统**：导出 `.saop` 备份完整进度

## 📦 模组市场

本仓库同时作为**全球模组仓库**，任何人都可以提交自己的模组。

### 📤 提交你的模组

1. 点击 **[New Issue](https://github.com/FI0m9ySans/fi0m9ysans.github.io/issues/new/choose)**
2. 选择对应的语言模板（中文 / English）
3. 填写模组信息并提交
4. 审核通过后，你的模组将出现在市场列表中

### 📂 模组文件格式

| 扩展名 | 内容 | 说明 |
|--------|------|------|
| `.shom` | 商品 + 背包 | 推荐格式 |
| `.shem` | 商品 + 背包 | 旧格式（兼容） |
| `.zid` | 商品 + 任务 + 自定义标签 | 完整模组，推荐格式 |
| `.zod` | 商品 + 任务 + 自定义标签 | 旧格式（兼容） |
| `.taem` | 任务清单 | 仅任务 |
| `.saop` | 完整存档 | 备份进度 |
