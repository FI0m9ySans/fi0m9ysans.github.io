Mod Development Guide

Learn how to create mods for Tomato Clock

Quick Start

A mod is a JSON file that adds new features to Tomato Clock. The simplest mod:

{
  "userItems": [
    {
      "id": "my_first_item",
      "name": "My First Item",
      "price": 10,
      "icon": "fa-star",
      "effect": "focus",
      "desc": "Adds 10 minutes of focus time!",
      "dependencies": []
    }
  ],
  "backpack": {},
  "tasks": [],
  "customTabs": [],
  "version": "1.0"
}

File Formats

.shom

Items + Backpack
Recommended

.zid

Items + Tasks + Tabs
Full Mod

.taem

Task List
Tasks only

.saop

Full Save
Backup progress

Effect Types

  • rest — Adds rest time (e.g. Rest 5 minutes)
  • focus — Adds focus time (e.g. Focus +10 minutes)
  • tomato — Rewards Tomato Coins (e.g. Get 2 Tomato Coins)
  • exp — Rewards EXP (e.g. Gain 25 EXP)
  • lootbox — Random lootbox reward
